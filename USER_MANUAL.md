## 1. Обзор

**Script Screen** — инструмент для написания и структурирования сценариев, построенный вокруг концепции визуальных карточек (карточек сцен). Каждая сцена представлена в виде карточки на доске, а её место в структуре задаётся атрибутом карточки «Индекс». Карточки связаны с действующими лицами, местами, деталями и временными периодами, что позволяет видеть общую структуру сценария и одновременно писать текст сцен в полноценном текстовом редакторе.

**Основные понятия:**

| Термин | Значение |
|---|---|
| **Проект** | Контейнер верхнего уровня, содержащий все данные сценария (название, версия, авторы) |
| **Сценарий** | Непосредственно сценарий — титульный лист, логлайн, синопсис и текст сцен |
| **Карточка (сцена)** | Одна сцена: порядковый номер, заголовок, описание и теги атрибутов |
| **Действующее лицо** | Персонаж или человек, появляющийся в сценарии |
| **Место** | Место, где происходит действие сцены |
| **Деталь** | Сюжетный элемент, мотив или предмет, связывающий сцены |
| **Время действия** | Временной маркер (например, «Утро», «Три дня спустя») |

## 2. Начало работы

### Установка

Script Screen распространяется одним архивом для Linux, Windows и macOS.
Распакуйте его и запустите установочный скрипт для вашей платформы — установщик
также настраивает компоненты, необходимые для транскрипции аудио (речевые модели
whisper.cpp и ffmpeg). Всё устанавливается под вашей учётной записью; права
администратора для самого приложения не требуются.

Полные пошаговые инструкции по установке, удалению и устранению неполадок см. в
**[DISTRIBUTION.ru.md](DISTRIBUTION.ru.md)** (то же руководство также входит в
каждый архив как `INSTALL.ru.md`, английская версия — `INSTALL.md`).

| Платформа | Команда установки |
|---|---|
| Linux  | `./install.sh` |
| macOS  | двойной клик по `install.command` (или `./install.command`) |
| Windows | правый клик по `install.ps1` ▸ **Выполнить с помощью PowerShell** |

> **Требования для транскрипции:** функция [транскрипции аудио](#транскрипция-аудио)
> опирается на whisper.cpp и речевые модели, установленные в `~/whisper.cpp`.
> Установщик размещает их за вас; если транскрипция не работает, проверьте, что
> эта папка существует (см. раздел устранения неполадок в DISTRIBUTION.ru.md).

### Создание нового проекта

1. Запустите приложение. По умолчанию открывается панель **Проект**.
2. Откройте меню (правый верхний угол) и выберите **Новый проект**.
3. В диалоговом окне введите:
   - **Название** — только буквы, цифры, символы `_`, `-` и `.`.
   - **Версия** — строка версии проекта (например, `1.0`).
4. Подтвердите. Новый проект создан и готов к работе.

### Открытие существующего проекта

1. В меню панели **Проект** выберите **Открыть проект**.
2. Найдите и выберите файл проекта `.json`.
3. Проект загружается вместе со всеми карточками, действующими лицами, местами, деталями и временными периодами.

> **Совет:** Приложение запоминает последний открытый проект и автоматически загружает его при следующем запуске.

### Сохранение

Проект сохраняется автоматически через настраиваемый интервал (автосохранение). Сохранение также запускается при любой операции с проектом (создание, открытие, экспорт). Кнопка «Сохранить» в процессе обычного редактирования не требуется.

## 4. Управление проектом

Доступно из панели **Проект**.

### Поля

| Поле | Описание |
|---|---|
| **Название** | Уникальный идентификатор проекта (буквы, цифры, `_`, `-`, `.`) |
| **Версия** | Строка версии проекта |
| **Язык** | Язык, используемый при транскрипции аудио |
| **Автор(ы)** | Одно или несколько имён авторов, связанных с проектом |

### Действия в меню

- **Новый проект** — создать новый пустой проект (текущие данные сохраняются перед очисткой).
- **Открыть проект…** — загрузить проект из файла `.json`.
- **Редактировать проект** — изменить название, версию, язык или авторов.
  Изменение **названия и/или версии** не перезаписывает текущий проект: при
  следующем сохранении создаётся **новая копия** — новый файл проекта `.json` и
  новый каталог под изменённым названием/версией, — а все файлы из прежнего
  каталога проекта копируются в него. Исходный проект остаётся нетронутым, так
  что каждое название/версия сохраняется как отдельная версия сценария. Изменение только
  **языка или авторов** обновляет существующий проект на месте.
- **Экспорт проекта** — экспортировать сценарий в формат PDF.
- **О программе** — показать версию приложения и сведения о лицензиях сторонних компонентов.
- **Выход** — сохранить и закрыть приложение.

> Пункты **О программе** и **Выход** доступны в меню каждой панели.

- **Выход** — сохранить и закрыть приложение.

## 6. Карточки (сцены)

Доступно из панели **Карточки**. Это основная рабочая панель.

### Доска

На доске все сцены отображаются в виде карточек, расположенных в сетке по четыре в ряд, в порядке возрастания их индексов. Порядок карточек на доске — это и есть порядок сцен в сценарии: чтобы переставить сцену, измените её **Индекс** в форме карточки (см. «Структура карточки»), и доска перестроится.

### Навигация по доске

- **Масштабирование (приближение / отдаление)** — прокручивайте **колёсико мыши** вверх для приближения и вниз для отдаления.
- **Перемещение всей доски** — нажмите и **удерживайте левую кнопку мыши на пустом месте** доски и тяните. Все карточки перемещаются вместе, что позволяет добраться до любой её части.

> Удержание левой кнопки на **карточке** перемещает эту карточку; удержание на **пустом месте** перемещает всю доску.

### Структура карточки

Каждая карточка содержит:
- **Индекс** — позиция сцены в сценарии и, соответственно, место карточки на доске (редактируется).
- **Заголовок / Описание** — краткое описание сцены.
- **Теги атрибутов** — действующие лица, места, детали и временные периоды, привязанные к сцене.

### Создание карточки

**Shift + Click** в любом пустом месте доски создаёт новую карточку сцены в этой позиции.

Справа (или ниже доски) открывается форма, в которой нужно заполнить:

| Поле | Описание |
|---|---|
| **Индекс** | Номер сцены (целое положительное число ≥ 1). Определяет порядок сцен в сценарии, положение карточки на доске и порядок сцен в PDF. Изменение индекса у существующей карточки переставляет её на новое место. |
| **Заголовок** | Краткое название сцены. |
| **Описание** | Краткое описание, отображаемое на карточке. |
| **Действующие лица** | Персонажи, участвующие в этой сцене (множественный выбор). |
| **Места** | Где происходит действие сцены (множественный выбор). |
| **Детали** | Сюжетные элементы или мотивы в этой сцене (множественный выбор). |
| **Время действия** | Временной период сцены (множественный выбор). |

### Редактирование карточки

- Нажмите **иконку карандаша** на карточке, чтобы открыть форму редактирования, **или**
- Нажмите на карточку, чтобы выделить её — форма появится автоматически.

Внесите изменения в форму. Изменения сохраняются при переходе к другой карточке или снятии выделения.

### Удаление карточки

Нажмите **иконку X** на карточке. Карточка и связанный с ней файл содержимого сцены удаляются безвозвратно.

### Перемещение и изменение размера карточек

- **Переместить**: перетащите карточку за заголовок или тело.
- **Изменить размер**: перетащите угловой маркер в правом нижнем углу карточки.

> **Это временное изменение вида.** Положение и размер карточки не сохраняются в
> проекте: при любом обновлении доски (добавление или удаление карточки, сохранение
> проекта, изменение фильтра, правый клик по доске, повторное открытие проекта)
> карточки возвращаются в сетку по четыре в ряд, в порядке индексов. Чтобы изменить
> структуру насовсем, правьте **Индекс** карточки, а не её положение на доске.

### Выделение и снятие выделения

- **Выделить**: нажмите на карточку. Её рамка станет **розовой**, содержимое загрузится в редактор.
- **Снять выделение**: нажмите на выделенную карточку ещё раз. Рамка вернётся к стандартному цвету, содержимое редактора сохранится и очистится.

Одновременно может быть выделена только одна карточка.

### Фильтрация карточек

На каждой карточке отображаются теги её атрибутов: **Действующие лица**, **Детали**, **Места** и **Время действия**. Нажатие на тег превращает его в фильтр, позволяя сосредоточиться на части сцен.

- **Включить фильтр** — нажмите любой тег атрибута на карточке. Тег подсветится, и на доске останутся видны только подходящие карточки; остальные будут скрыты.
- **Сочетать фильтры** — нажимайте дополнительные теги, чтобы добавить атрибуты к фильтру. Карточка остаётся видимой, если соответствует **хотя бы одному** из активных атрибутов (логика «ИЛИ»), а не всем сразу.
- **Снять фильтр** — нажмите подсвеченный тег ещё раз, чтобы убрать атрибут из фильтра. Когда нет активных тегов, видны все карточки.

> Фильтр видимости сопоставляет карточку по всем её атрибутам — **Действующим лицам**, **Деталям**, **Местам** и **Времени действия**.

Полное описание см. в разделе [Фильтрация](#12-фильтрация).

### Транскрипция аудио

Сначала нужно **выделить** карточку сцены — распознанный текст вставляется в содержимое именно этой сцены. Для транскрипции используется языковая настройка проекта.

- **Транскрибировать аудиофайл…** — преобразовать существующий аудиофайл (MP3, WAV, M4A) в текст и поместить его в выбранную сцену. (Недоступно, пока не выделена карточка.)
- **Начать живую транскрипцию** — начать распознавание речи с микрофона в реальном времени, добавляя текст в выбранную сцену по мере произнесения.
- **Остановить живую транскрипцию** — остановить выполняющуюся живую транскрипцию. (Этот пункт заменяет *Начать живую транскрипцию*, пока транскрипция выполняется.)

### Действия в меню

- **Транскрибировать аудиофайл…** — транскрибировать аудиофайл в выбранную сцену (доступно только при выделенной карточке).
- **Начать / Остановить живую транскрипцию** — переключить распознавание речи с микрофона в реальном времени в выбранную сцену.
- **Показать / Скрыть редактор** — переключить окно текстового редактора сценария (см. [Редактор сценария](#11-редактор-сценария)).
- **О программе** — показать версию приложения и сведения о лицензиях сторонних компонентов.
- **Выход** — сохранить и закрыть приложение.

## 7. Действующие лица

Откройте форму редактирования действующего лица и нажмите кнопку **Удалить**.

> Удаление действующего лица снимает его со всех карточек сцен, к которым оно было привязано.

## 11. Редактор сценария

Редактор — это полноценный текстовый редактор (TinyMCE), открывающийся в отдельном окне рядом с доской.

### Показать и скрыть редактор

В меню панели **Карточки** выберите **Показать редактор** или **Скрыть редактор**, чтобы переключить видимость окна редактора.

### Принцип работы редактора

- При **выделении** карточки сцены её содержимое загружается в редактор.
- Пишите и форматируйте текст сцены в редакторе.
- При **выделении другой карточки** текущее содержимое **автоматически сохраняется** перед загрузкой новой сцены.
- При **снятии выделения** с карточки содержимое сохраняется и редактор очищается.
- При **удалении** карточки связанный файл содержимого удаляется безвозвратно.

### Форматирование

Редактор TinyMCE поддерживает стандартное форматирование текста:

- **Жирный**, *курсив*, подчёркивание
- Заголовки (H1–H6)
- Маркированные и нумерованные списки
- Стили абзацев

## 12. Фильтрация

На доске **Карточки** можно фильтровать отображаемые карточки, нажимая на теги атрибутов, показанные на каждой карточке.

### Как использовать фильтр

1. Найдите теги атрибутов на любой карточке (действующие лица, детали, места, время действия).
2. Нажмите на тег, чтобы активировать фильтр. Тег подсветится.
3. На доске останутся видны только карточки, **помеченные этим атрибутом**; остальные будут скрыты.
4. Нажмите на тег повторно, чтобы снять фильтр.

Одновременно могут быть активны несколько фильтров. Карточка отображается, если она соответствует **хотя бы одному** из активных фильтров (логика «ИЛИ»).

> **Какие атрибуты фильтруют:** фильтр видимости применяется ко всем атрибутам карточки — **Действующим лицам**, **Деталям**, **Местам** и **Времени действия**.

Когда нет активных тегов, видны все карточки.

## 14. Хранение данных

### Формат файла

Проекты хранятся в виде **JSON-файлов** (`.json`). Каждый файл проекта содержит все метаданные: карточки, действующие лица, места, детали, временные периоды и сводку сценария.

### Содержимое сцен

Текст каждой сцены хранится в отдельном **HTML-файле** в папке проекта. Эти файлы создаются и управляются автоматически.

### Папка проекта

При создании или версионировании проекта создаётся папка с временно́й меткой, в которой хранятся все связанные файлы. Не переименовывайте и не перемещайте эти файлы вручную.

При изменении **названия или версии** проекта и сохранении приложение создаёт новый проект как копию: записывается новый файл проекта `.json` под изменённым названием/версией и новый каталог, после чего каждый файл из прежнего каталога проекта копируется в новый. Предыдущее название/версия остаётся на диске без изменений, поэтому переименование или смена версии работает как **«Сохранить как»**, а не как переименование на месте.

### Правила проверки данных

| Поле | Правило |
|---|---|
| Название проекта / сценария | Только буквы, цифры, `_`, `-`, `.` |
| Номер карточки | Целое положительное число ≥ 1 |
| Поля «Название» (лица, места и т.д.) | Не может быть пустым |
| Поля «Описание» | Необязательны |

## 15. Настройки приложения (`app_settings.json`)

Глобальные настройки приложения хранятся в файле **`app_settings.json`**, расположенном в папке `assets/cfg` приложения. Файл читается один раз при запуске, а некоторые значения (например, последний открытый проект) записываются обратно автоматически во время работы. Обычно его не требуется редактировать вручную, но перечисленные ниже параметры позволяют настроить поведение приложения.

> **Примечание:** редактируйте файл только при закрытом приложении и сохраняйте корректный формат JSON. При недопустимом значении используется встроенное значение по умолчанию, если оно предусмотрено.

| Параметр | Тип | Пример | Описание |
|---|---|---|---|
| `app_name` | строка | `"scriptscreen"` | Внутренний идентификатор приложения. Используется как имя журнала (logger) и префикс имён ежедневных файлов логов. |
| `last_project` | строка | `"/home/user/scripts/memoirs_1.0_….json"` | Полный путь к последнему открытому проекту. Обновляется автоматически при создании или открытии проекта и перезагружается при следующем запуске. Если файл отсутствует или путь пуст, при запуске создаётся новый проект. |
| `language` | строка | `"en_US"` | Язык интерфейса, выбираемый при запуске. Приводится к двухбуквенному коду (например, `en`, `ru`); неподдерживаемое значение заменяется на английский. |
| `default_autosave` | целое (секунды) | `300` | Интервал между автоматическими сохранениями проекта и содержимого сцен. |
| `gui_primary_color` | строка | `"green"` | Основной акцентный цвет интерфейса. Допустимые значения: `red`, `blue`, `black`, `green`, `yellow`, `amber`, `cyan`, `brown`, `orange`, `purple`, `grey`, `lime`, `pink`. Неизвестное значение заменяется на `blue`. |
| `editor_config` | строка | `"editor.html"` | Имя файла конфигурации текстового редактора (TinyMCE), загружаемого для редактора сценария. |
| `note_header_template` | строка | `"header.html"` | HTML-шаблон (в `assets/cfg`), используемый для построения заголовков сцен при экспорте сценария. |
| `log_level` | строка | `"INFO"` | Уровень детализации логирования. Допустимые значения: `ALL`, `OFF`, `FINEST`, `FINER`, `FINE`, `CONFIG`, `INFO`, `WARNING`, `SEVERE`, `SHOUT`. Нераспознанное значение включает `ALL`. |
| `transcribe_fmt` | строка | `"txt"` | Формат результата, создаваемого службой транскрипции аудио. |
| `whisper_model` | строка | `"large-v3-turbo-q8_0"` | Модель whisper.cpp для транскрипции аудио**файлов**. Должна быть установлена в `~/whisper.cpp`. |
| `whisper_live_model` | строка | `"small"` | Модель whisper.cpp для **живой** транскрипции с микрофона. Для работы в реальном времени рекомендуется меньшая и более быстрая модель. |
