# ScriptScreen

**Пишите сценарий на доске сюжетных карточек.**

ScriptScreen — бесплатное приложение с открытым исходным кодом для написания
сценариев. Каждая сцена это карточка на бесконечной доске: перетащите её на нужное
место, отметьте действующими лицами, местом, деталями и временем действия, затем
кликните по тегу — и на доске останутся только сцены этой линии. Текст сцены пишется
во встроенном редакторе или надиктовывается: распознавание речи работает локально, на
вашем компьютере. Готовый сценарий выгружается в PDF.

Linux и Windows. Интерфейс на русском и английском. Лицензия Apache 2.0.

## Возможности

- **Сюжетные карточки на бесконечной доске** — перетаскивание, изменение размера,
  зум и панорамирование; новая сцена по Shift+клик.
- **Четыре измерения тегов** — действующие лица, места, детали и время действия.
- **Фильтрация в один клик** — клик по тегу оставляет на доске только его сцены; теги комбинируются.
- **Встроенный редактор сценария** — полноценное форматирование текста, автосохранение.
- **Офлайн-диктовка** — расшифровка аудиофайлов и живой речи с микрофона через
  whisper.cpp, локально.
- **Титульная информация** — титульный лист, логлайн и синопсис хранятся вместе со сценарием.
- **Экспорт в PDF** — собранный сценарий, сцены в порядке нумерации.
- **Файлы остаются вашими** — проект это обычный JSON и HTML-файлы сцен на вашем диске;
  смена названия или версии сохраняет отдельную версию сценария, не затирая предыдущую.
- **Без аккаунта, без облака, без телеметрии.**

## Установка

Скачайте архив для своей платформы из
[релиза v1.3.1](https://github.com/khomisha/scriptscreen/releases/tag/v1.3.1),
распакуйте и запустите установочный скрипт. Всё устанавливается в вашу
пользовательскую папку — права администратора не требуются.

| Платформа | Загрузка | Команда установки |
|---|---|---|
| Linux | [`scriptscreen-1.3.1-linux.tar.gz`](https://github.com/khomisha/scriptscreen/releases/download/v1.3.1/scriptscreen-1.3.1-linux.tar.gz) | `./install.sh` |
| Linux, GPU | [`scriptscreen-1.3.1-linux-gpu-vulkan.tar.gz`](https://github.com/khomisha/scriptscreen/releases/download/v1.3.1/scriptscreen-1.3.1-linux-gpu-vulkan.tar.gz) | `./install.sh` |
| Windows | [`scriptscreen-1.3.1-windows.zip`](https://github.com/khomisha/scriptscreen/releases/download/v1.3.1/scriptscreen-1.3.1-windows.zip) | правый клик по `install.ps1` ▸ **Выполнить с помощью PowerShell** |
| Windows, GPU | [`scriptscreen-1.3.1-windows-gpu-vulkan.zip`](https://github.com/khomisha/scriptscreen/releases/download/v1.3.1/scriptscreen-1.3.1-windows-gpu-vulkan.zip) | правый клик по `install.ps1` ▸ **Выполнить с помощью PowerShell** |

**Какой архив выбрать?** Обычный распознаёт речь на процессоре и работает везде.
Архив `gpu-vulkan` считает речевые модели на видеокарте с поддержкой Vulkan —
диктовка, особенно живая, идёт заметно быстрее. Если не уверены, берите обычный.

Установщик также разворачивает компоненты для диктовки: речевые модели whisper.cpp
и ffmpeg — в каталог `~/whisper.cpp`.

macOS поддерживается кодом, но готовой сборки пока нет — её можно собрать из
исходников командой `dist/make-dist.sh --platform macos`
(см. [DISTRIBUTION.ru.md](DISTRIBUTION.ru.md)).

Полные инструкции по установке, удалению и решению проблем:
[DISTRIBUTION.ru.md](DISTRIBUTION.ru.md) ([en](DISTRIBUTION.md)). Та же инструкция
входит в каждый архив как `INSTALL.ru.md` / `INSTALL.md`.

## С чего начать

1. Откройте приложение и создайте проект (панель **Проект** ▸ меню ▸ *Новый проект*).
2. Перейдите на панель **Карточки** и добавьте первую карточку по **Shift+клик** на доске.
3. Заведите действующих лиц, места, детали и время действия на своих панелях и
   отметьте ими карточку.
4. Выберите карточку и напишите сцену в редакторе — или надиктуйте её.
5. Выгрузите готовый сценарий в PDF с панели **Проект**.
