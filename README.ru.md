# ScriptScreen

**Пишите сценарий на доске сюжетных карточек.**

ScriptScreen — бесплатное приложение с открытым исходным кодом для написания
сценариев. Каждая сцена это карточка на бесконечной доске: её место в структуре
задаётся атрибутом «индекс», отметьте её действующими лицами, местом, деталями и
временем действия, затем кликните по тегу — и на доске останутся только сцены этой
линии. Текст сцены пишется
во встроенном редакторе или надиктовывается: распознавание речи работает локально, на
вашем компьютере. Готовый сценарий выгружается в PDF.

Linux и Windows. Интерфейс на русском и английском. Лицензия Apache 2.0.

> 🇬🇧 English version: [README.md](README.md)

## Возможности

- **Сюжетные карточки на бесконечной доске** — зум и панорамирование; новая сцена
  по Shift+клик.
- **Порядок сцен — атрибут карточки** — «индекс» в форме карточки задаёт её место на
  доске и в готовом сценарии; чтобы переставить сцену, достаточно изменить число.
- **Четыре измерения тегов** — действующие лица, места, детали и время действия.
- **Фильтрация в один клик** — клик по тегу оставляет на доске только его сцены; теги комбинируются.
- **Встроенный редактор сценария** — полноценное форматирование текста, автосохранение.
- **Офлайн-диктовка** — расшифровка аудиофайлов и живой речи с микрофона через
  whisper.cpp, локально.
- **Титульная информация** — титульный лист, логлайн и синопсис хранятся вместе со сценарием.
- **Экспорт в PDF** — собранный сценарий с титульным листом и оглавлением, сцены в
  порядке индексов.
- **Файлы остаются вашими** — проект это обычный JSON и HTML-файлы сцен на вашем диске;
  смена названия или версии сохраняет отдельную версию сценария, не затирая предыдущую.
- **Без аккаунта, без облака, без телеметрии.**

## Установка

Откройте
[страницу релизов](https://github.com/khomisha/scriptscreen/releases/latest),
скачайте архив для своей платформы, распакуйте и запустите установочный скрипт.
Всё устанавливается в вашу пользовательскую папку — права администратора не
требуются. В именах файлов ниже `<версия>` — версия выбранного релиза.

| Архив | Что это | Команда установки |
|---|---|---|
| `scriptscreen-<версия>-linux.tar.gz` | Linux, x86-64. Речь распознаётся на процессоре — работает на любой машине, видеокарта не нужна. | `./install.sh` |
| `scriptscreen-<версия>-linux-gpu-vulkan.tar.gz` | Та же сборка для Linux, но речевые модели считаются на видеокарте с поддержкой Vulkan: диктовка, особенно живая, идёт заметно быстрее. | `./install.sh` |
| `scriptscreen-<версия>-windows.zip` | Windows 10/11, x86-64. Речь распознаётся на процессоре — работает на любой машине, видеокарта не нужна. | правый клик по `install.ps1` ▸ **Выполнить с помощью PowerShell** |
| `scriptscreen-<версия>-windows-gpu-vulkan.zip` | Та же сборка для Windows, речевые модели считаются на видеокарте с поддержкой Vulkan — диктовка быстрее. | правый клик по `install.ps1` ▸ **Выполнить с помощью PowerShell** |

Если не уверены, берите обычный (CPU) архив: он работает везде, а GPU-версия
меняет только скорость диктовки, но не возможности программы.

Установщик также разворачивает компоненты для диктовки: речевые модели whisper.cpp
и ffmpeg — в каталог `~/whisper.cpp`.

macOS поддерживается кодом, но готовой сборки пока нет — её можно собрать из
исходников командой `dist/make-dist.sh --platform macos`
(см. [DISTRIBUTION.ru.md](DISTRIBUTION.ru.md)).

Полные инструкции по установке, удалению и решению проблем:
[DISTRIBUTION.ru.md](DISTRIBUTION.ru.md) ([en](DISTRIBUTION.md)). Та же инструкция
входит в каждый архив как `INSTALL.ru.md` / `INSTALL.md`.

## С чего начать

1. Откройте приложение и создайте проект (панель **Проект** ▸ меню ▸ *Новый проект*).
2. Перейдите на панель **Карточки** и добавьте первую карточку по **Shift+клик** на доске.
3. Заведите действующих лиц, места, детали и время действия на своих панелях и
   отметьте ими карточку.
4. Выберите карточку и напишите сцену в редакторе — или надиктуйте её.
5. Выгрузите готовый сценарий в PDF с панели **Проект**.
